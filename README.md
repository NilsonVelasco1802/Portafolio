# 🌐 Portafolio Web Personal - Nilson Velasco

Este repositorio contiene el código fuente de mi portafolio web personal, diseñado para presentar mis proyectos, habilidades técnicas y experiencia profesional de manera clara, moderna y responsiva.

## 📁 Estructura del Proyecto

El proyecto está organizado de forma sencilla y modular utilizando tecnologías web estándar:

```
Portafolio/
├── css/
│   ├── index.css             # Estilos específicos de la página principal y secciones
│   └── style.css             # Estilos globales, variables y reglas responsivas
├── img/
│   ├── nilson-velasco-foto-banner.jpg  # Fotografía principal del banner
│   ├── project-1.jpg         # Vista previa del Proyecto 1
│   ├── project-2.jpg         # Vista previa del Proyecto 2
│   └── project-3.jpg         # Vista previa del Proyecto 3
├── src/
│   └── menuHamburguesa.js    # Lógica interactiva para el menú de navegación móvil
└── index.html                # Estructura principal del sitio web

```

## 🚀 Tecnologías Utilizadas

* **HTML5:** Maquetación semántica del contenido.

* **CSS3:** Diseño visual, estilos personalizados y adaptación a dispositivos móviles (*Responsive Design*).

* **JavaScript (Vanilla):** Interactividad del sitio, incluyendo la funcionalidad del menú hamburguesa para pantallas pequeñas.

* **Git:** Control de versiones del proyecto.

## ✨ Características Principales

* **Diseño Responsivo:** Adaptable a computadoras de escritorio, tabletas y teléfonos móviles.

* **Menú de Navegación Interactivo:** Menú desplegable implementado con JavaScript puro (`menuHamburguesa.js`) para mejorar la experiencia de usuario en móviles.

* **Galería de Proyectos:** Sección dedicada a mostrar trabajos destacados con sus respectivas imágenes de vista previa.

* **Presentación Personal:** Banner principal con información de perfil e imagen destacada.

## 💻 Cómo Ejecutar el Proyecto Localmente

Al ser un proyecto web estático, no requiere instalación de dependencias ni servidores complejos:

1. **Clona este repositorio** en tu máquina local:

   ```
   git clone https://github.com/NilsonVelasco1802/Portafolio.git
   
   ```

2. **Ingresa a la carpeta** del proyecto:

   ```
   cd Portafolio
   
   ```

3. **Abre el archivo `index.html`** directamente en tu navegador web preferido (o utiliza una extensión como *Live Server* en Visual Studio Code para recarga automática).
